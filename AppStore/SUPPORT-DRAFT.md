# 书架帮助与支持（发布草案）

发布前替换正式应用名，填写开发者名称、联系邮箱和回复安排。本文件尚未公开发布。

## 开始使用

点击加号手动添加书籍；魔棒可按书名或 ISBN 查询豆瓣、Goodreads 和 Open Library。可选择单站或全部已启用来源，各来源独立显示结果与错误。选择一本书后预览作者、出版社和版本，再填入编辑页保存。ISBN 缺失或与查询不同会显示提示。设置里停用的解析器不参与搜索。无需先复制网页链接。

## 从豆瓣或 Goodreads 网页添加

点击工具栏的链接按钮，粘贴豆瓣或 Goodreads 图书详情页链接并提取；也可粘贴网站首页，选择一本书。核对预览，点击“填入编辑页”后保存。设置 → 网页解析器可以分别启用、停用和测试解析器。

Goodreads 还支持搜索结果、公开文件夹（list/show）和分类书架（shelf/show）页面。出版信息按当前链接对应的版本提取，缺失 ISBN 等字段时留空，不以作品首次出版日期代替当前版本日期。

如果网站限制应用访问，在浏览器打开该详情页并保存为 HTML；保持输入框中的原始页面链接，选择“导入已保存网页…”。本机解析不加载网页引用资源，不需要在应用中登录。验证码页面无法提取；遇到网页结构变化仍可手动录入。导入前请确认原始链接与保存的书籍一致。

## 扩展其他网站

设置 → 网页解析器 → 管理网页解析器，可导出规则模板，再按目标网站填写域名、路径和字段 XPath，导入后即可使用，无需重新编译。导入时会显示名称、版本、网页范围。每个解析器支持单独启用和测试；测试只预览，不写入书库。自定义规则需要单独导出备份，导入同 ID 的规则可更新，原启用状态保留。

规则适用于页面已有的 HTML 信息，不保证任意网站或动态页面均能提取。完整规则格式和本地演示见项目的 [Docs/TRANSLATORS.md](../Docs/TRANSLATORS.md)。不能直接导入 Zotero 的 JavaScript 文件。

## 数据与备份

书库顶部「导入/导出」支持 RIS 图书导入，先核对重复和字段提示，再确认写入；文章、章节及缺少书名的条目会跳过。每条记录需包含 TY 和 ER；截断或编码错误的文件不会部分写入。支持 UTF-8 或带 BOM 的 UTF-16，单次最多 10 MB / 5000 条。文件中的附件不会访问或下载。

也可导出当前筛选结果或所选书籍为 RIS / CSV；设置 → 书目交换可导出全部未删除书籍。个人笔记默认不包含，可自行勾选。CSV 便于表格查看，暂不支持导入。RIS/CSV 不保留全部应用字段、回收站和智能文件夹，完整迁移请使用 JSON 备份。

书库在本机应用沙盒中，目前没有跨设备同步。在设置中定期导出 JSON 备份，妥善保管其中的个人笔记。

## 更换电脑或正式版

从旧版本导出备份，在新应用中选择“从备份恢复”。应用先显示冲突预览：冲突默认跳过，可选择添加为新记录、仅补全空白，或采用导入的出版信息。更新会汇总笔记、标签和文件夹；不同有效 ISBN 不能互相覆盖。执行前不会改动书库。新备份格式为版本 4，包含文件夹层级、独立笔记、书籍子笔记、回收站和智能文件夹，可导入版本 1、2、3 的旧备份；旧版应用无法读取新版备份。预览中可核对智能文件夹的条件并选择是否导入，同名或同 ID 保留本地，文件内同名定义也会跳过。
更换 Bundle ID 后可能使用新沙盒，通过 JSON 迁移，不直接覆盖数据库文件。

## 高级筛选与智能文件夹

书库顶部「高级筛选」（⌥⌘F）可以组合作者、出版社、出版年份、标签、缺失 ISBN 等条件，选择满足全部或任一，并即时预览结果。高级筛选只查询本地书库；应用时从全部未删除书籍开始，清除当前搜索与标签条件。

勾选「保存为智能文件夹」并命名，侧栏就会显示动态结果。书籍信息变化时，成员自动更新，不会复制书籍。可从顶部「编辑规则」或侧栏右键修改，右键移除仅删除规则。创建、修改、移除均支持当前窗口的撤销和重做，智能文件夹随书库备份保存。

## 检索失败

尝试完整书名或 ISBN，并检查网络。部分中文书籍可能没有资料，可以手动输入。不要在检索框输入个人隐私信息。

## 删除数据

右键书籍 → 移入回收站。元信息、笔记、分类仍保留，可在侧栏「回收站」恢复；永久删除或清空回收站需要确认，且不可撤销。导出的备份需另行保管或删除。

## 更新元信息与合并重复书籍

编辑书籍时搜索或提取网页信息，随后逐字段比较当前值和新值。默认只勾选空白字段；可单独选择作者、出版社、日期、ISBN、简介。缺失的新值不会清空原内容。点击“应用所选字段”后仍需保存编辑页。

侧栏「疑似重复」列出可能重复的记录，多选后点击“整理所选 → 合并”。选择主记录和各字段来源，预览后确认；笔记、标签、文件夹和丛书汇总，其他原记录移入回收站。不同有效 ISBN 保留为不同版本，不能合并。原记录的其他值可在回收站查看。

## 撤销与重做

多选书籍后，右侧「批量编辑…」可统一设置标签和常用出版信息。出版字段可选择仅补空白、替换或清空；标签可分别添加和移除。右侧逐本显示差异，核对后点击「应用到 N 本书」，整批修改可以一次撤销。未变化的书籍不更新修改时间；若预览期间书籍被修改，会停止整批操作，请重新打开预览。

添加、编辑、导入、整理、移入回收站、恢复和合并支持当前窗口会话内的撤销/重做。使用系统“编辑”菜单；输入框聚焦时快捷键优先撤销文字。退出后撤销历史清空，回收站持续保留。若记录随后被修改，撤销会停止并提示核对，避免覆盖新内容。

系统“编辑”菜单提供“撤销”“重做”；设置的备份区域保留撤销和重做按钮。导入在设置窗口执行，可在设置中撤销。各窗口历史相互独立。

## 核对重复组与字段来源

在「疑似重复」顶部选择重复组，可查看匹配依据并打开整组合并预览。仅同名的书需要核对作者和版本；缺少 ISBN 的记录若关联到多个有效 ISBN，会禁用整组合并，请先编辑补全信息或手动选择同一版本的记录。

选中书籍 → 详情面板「来源」，可查看书名、作者、出版社等字段的来源和提取时间。手动修改单个字段后，该字段会标记为手动编辑。旧记录只有整体来源时显示“历史来源，未逐字段记录”；没有来源时显示“手动录入或未记录来源”。回收站也能查看完整出版信息、笔记、分类和来源，需恢复后才可编辑。

## 如何编辑笔记？

展开书籍，选中下方笔记，直接在右侧修改正文；独立笔记工作区也使用同一个编辑面板。内容自动保存到本机，不需要弹窗或保存按钮。右键书籍 → 新建笔记会立即创建空白条目并进入编辑，可以撤销。正常保存时不显示状态栏；若保存失败，会出现错误提示，可重试或另存为新笔记；请在备份前将草稿成功保存。

新笔记直接写正文即可，首行会自动用作列表名称。右侧默认只有格式工具栏和正文，四周没有灰色卡片留白；原有名称、标签和文件夹关联仍保留，但不再显示这些编辑字段。正文为所见即所得编辑：输入 `# ` 变为标题，`**文字**` 变为加粗，`- ` 变为列表；也可用工具栏直接修改选区。无需切换预览。列表按回车续写，空项再按回车退出；自动转换可以用 ⌘Z 单独撤销。链接按钮可填写网址，粘贴 Markdown 也会直接转换。已有内容不会因打开而改写，实际编辑后以 Markdown 自动保存；格式随 JSON 备份保留。包含空名称笔记的备份请使用当前或更新版本恢复。

如需删除笔记，在条目上右键选择「移入回收站」；独立笔记工作区和书籍下方的子笔记均支持，之后可以撤销或从笔记回收站恢复。
