# Bookshelf

上架准备入口：[发布准备与待办](AppStore/RELEASE-READINESS.md)。商店文案、审核说明和支持页草案位于 AppStore 目录。名称和定价尚未确定，材料均为草案。

运行 `bash scripts/build-release.sh` 可检查未签名的双架构 Release 产物；正式包还需通过 `python3 scripts/preflight.py --app "/path/to/Bookshelf.app" --submission`。脚本不上传或发布，也不替代 Organizer 验证。

一款本地优先、使用 SwiftUI 与 SwiftData 构建的 macOS 原生书籍元信息管理器。

## 核心架构

已按 Zotero 的窗口/核心分离、数据 API、事务通知及四类 translator 机制重构。现有功能通过统一命令与数据访问层运行；编辑器和笔记有过期草稿保护，普通书单的新建/重命名可撤销。详见 [架构对照、数据流与扩展边界](ARCHITECTURE.md)。

## 当前能力

- 封面墙和列表视图
- 手动添加、编辑、移入回收站与恢复书籍
- 按书名或 ISBN 从豆瓣、Goodreads、Open Library 检索，按来源显示候选，预览后填充
- 从豆瓣或 Goodreads 的图书详情、首页等公开页面提取元信息，预览后填充（可选封面）
- 作者、译者、标签、书单和丛书数据模型
- 搜索、高级组合筛选、动态智能书单和排序
- 阅读状态、评分、收藏和个人备注
- 多层子书单、移动层级、可选汇总子书单；移除层级时保留内容，支持撤销
- 独立笔记与每书多条子笔记、标签、正文检索、回收站，以及旧备注转换
- 右侧原生 Markdown 编辑器、格式工具和预览；标题可选，默认以正文首行自动命名
- 原生层级列表：书籍可展开显示下方笔记，选择笔记查看详情，排序时保持父子归属
- 将用户选择的封面复制到应用沙盒
- 保存前按 ISBN、书名和作者提示可能的重复书籍
- 包含封面和回收站状态的 JSON 备份，导入前预览冲突并选择处理方式
- 元信息逐字段对比更新、重复书籍合并、原生撤销与重做
- 多选批量编辑标签、评分、阅读状态、收藏和出版信息，逐本预览后应用
- RIS 书目导入导出、CSV 清单导出，可按当前筛选或所选书籍导出，个人笔记默认排除
- 重复候选按组核对并显示原因；详情面板可查看逐字段来源，回收站支持完整只读预览
- 完整的 macOS AppIcon 尺寸集和应用内隐私政策入口
- App Sandbox 配置，仅允许用户选择的文件访问和主动发起的网络检索

## 书库整理界面

参考 Zotero 的三栏信息结构：左侧书库、阅读状态、书单与标签；中间书籍表格或封面墙；右侧可收起的详情面板。

- 表格显示书名、作者、出版社、出版日期和阅读状态，点击列标题排序，双击条目编辑。
- 表格支持 Command 多选和 Shift 连选；封面墙支持 Command 多选。右键或「整理所选」可批量设置阅读状态、收藏和书单归属。
- 在侧栏创建书单，右键可新建子书单、重命名或移动层级。同一本书可加入多个书单；「从当前书单移除」只解除该书单归属。父级默认不汇总后代，可勾选「包含子书单」。
- 侧栏标签支持名称搜索与多标签交集筛选，可与当前书单和书库搜索同时使用。
- 详情面板分为「信息」「笔记」「整理」。状态、评分、收藏与标签/书单修改会保存；笔记直接在右侧编辑并自动保存到本机。
- 工具栏魔棒按钮或 Shift-Command-I 打开书名 / ISBN 检索；Option-Command-I 显示或隐藏详情面板。

搜索入口默认查询全部已启用来源，也可选择单站。各来源独立加载并显示失败原因；点选候选后读取具体版本的详情。ISBN 缺失或与查询不符会提示核对，ISBN-10 与对应 ISBN-13 视为同一号码。封面默认不下载，可在预览中勾选。设置里停用豆瓣、Goodreads 或 Open Library 后，该来源停止参与搜索。RIS / CSV 也通过同一设置管理。
- 在当前书单内点击工具栏「添加书籍」，新书会预选该书单；编辑已有书籍会保留其全部书单归属。

参考：[Zotero 基础界面](https://www.zotero.org/support/quick_start_guide)、[书单与标签](https://www.zotero.org/support/collections_and_tags)。

## 安全整理与更新

- 设置 → 从备份恢复：先预览新增与冲突，逐条选择跳过、添加为新记录、补全空白或采用导入的出版信息。冲突默认跳过；不同有效 ISBN 的版本不能互相覆盖。更新会汇总笔记、标签和书单，个人评分与阅读状态优先保留本地。
- 删除只移入侧栏「回收站」，保留元信息、笔记、分类和封面；可批量恢复。永久删除和清空回收站另行确认，不能撤销。
- 搜索或网页提取后显示字段对比，默认仅勾选空白字段；未提供的值不会清空已有内容，封面也可单独选择。应用字段后仍需在编辑页保存。
- 侧栏「疑似重复」显示可能重复的记录。选择两本以上 → 整理所选 → 合并，选择主记录与各字段来源；汇总笔记、标签、书单、丛书，其他原记录移入回收站。ISBN-10 与对应 ISBN-13 视为同一版本；不同有效 ISBN 不允许合并。
- 本次窗口会话中，添加、编辑、导入、整理、移入回收站、恢复和合并支持「编辑 → 撤销/重做」。输入框聚焦时快捷键优先撤销文字输入，书库顶部也有撤销按钮。退出后撤销历史不保留，回收站仍保留。如果记录在操作后发生了未追踪的修改，撤销会停止以免覆盖新内容。
- 新备份格式为 schemaVersion 4，可读取旧版 1/2/3；旧版应用不能读取新格式。备份包含回收站、字段来源、智能条件、空书单与父子层级、独立笔记和子笔记。导入预览可核对并取消书单/笔记部分，同 ID 笔记保留本地；自定义解析规则仍需另行导出。

## 子书单与独立笔记

工具栏「新建笔记」支持独立笔记和书籍子笔记；侧栏的笔记工作区可检索标题、正文与标签。编辑器可选择所属书籍，或保持独立并加入多个书单。书籍详情的「笔记」面板支持每书多条笔记，原有单份笔记作为书籍备注保留，可一键转为子笔记并撤销。

笔记使用右侧原生 Markdown 编辑器，提供格式工具和同面板预览，输入后自动保存；新建和编辑均无单独弹窗。无需填写标题，列表默认以正文首行命名；也可展开「笔记名称（可选）」设置固定名称。保存失败时保留草稿，可重试或另存；删除进入笔记回收站。书籍合并和撤销会同步处理子笔记关联。详见 [操作说明、备份规则与限制](ORGANIZATION.md)。

在「疑似重复」中使用「重复组」选择器，自动选中一组并显示匹配原因：ISBN 相同、书名与作者关联，或仅书名相同。缺少有效 ISBN 的记录可能把不同版本关联在一起，此时会提示先核对并禁用整组合并；已知的不同 ISBN 不会直接视为重复。选择分组会清除搜索与标签筛选，之后增加筛选时需清除筛选再整组合并。识别使用索引分组，避免逐本扫描整库。

详情面板的「来源」页展示字段采用的来源链接与时间（如已记录）。新提取的信息会记录逐字段来源；手动修改仅把对应字段标记为手动编辑。旧记录只有整体来源时明确标注“历史来源，未逐字段记录”，不会当成已核实的逐字段来源。更新和合并预览也会显示来源。回收站保留同样的信息、笔记、整理和来源页，恢复前只读。

书库顶部与设置中的备份区域都有撤销、重做按钮，悬停和辅助功能标签会显示操作名称；无可用历史时按钮禁用。设置与书库窗口分别保留各自的操作历史。

## 高级筛选与智能书单

点击书库顶部「高级筛选」或按 Option-Command-F，组合书名、作者、译者、出版社、出版年份、ISBN、语言、标签、普通书单、阅读状态、评分、页数、笔记、元信息来源、封面和收藏条件。可以选择「满足全部」或「满足任一」，实时查看匹配数量与前 10 本书；应用后查看全部结果。

「常用条件」提供待补全 ISBN、尚未评分、高分已读和有笔记的书。评分按 0.5–5 星、半星递增；年份按当前版本出版日期的四位年份筛选。数值未知时不会匹配数值比较，请用「为空」查找缺失信息。文本忽略大小写、全半角与音调，ISBN 等值比较识别对应的 ISBN-10/13。

应用高级筛选会从全部未删除书籍开始，并清除当前搜索与标签条件。之后可叠加顶部搜索、标签和侧栏分类；切换智能书单会清除临时筛选，回收站不应用高级筛选。

勾选「保存为智能书单」并命名，或在侧栏点击「新建智能书单」。智能书单保存筛选条件，随书籍信息变化自动更新，不复制记录，也无需手动加入书籍。可从顶部「编辑规则」或侧栏右键编辑、移除；移除只删除定义，书籍仍保留。创建、编辑和移除支持当前窗口的撤销/重做，规则随 JSON 备份导出，纯智能书单备份也能导入。

## 批量编辑

在列表或封面墙中多选书籍，点击右侧「批量编辑…」，或从「整理所选」/右键菜单进入「批量编辑标签与信息…」。默认所有字段保持原样；右侧列出所选书籍及每本的修改数量，点选即可查看当前值与修改后的值。

- 出版社、出版日期、版次、语言和个人评分支持「保持原样」「仅补空白」「替换为」「清空」。仅补空白保留已有内容；填写空字符串不能代替清空。评分为 0.5–5 星，半星递增。
- 可统一阅读状态和收藏。修改阅读状态不会自动填写开始或完成阅读日期。
- 标签可批量添加、从现有标签中选择，或勾选从所选书籍移除的标签；标签旁显示在所选书籍中的使用数量。忽略大小写、全半角和音调进行去重，同一标签不能同时添加和移除。其他标签以及未选中的书籍保持原样。
- 没有实际差异的书籍不写入，也不改变修改时间。实际修改的出版字段标记为「手动编辑」，其他字段来源、个人笔记、作者、书单和丛书保留。智能书单随修改结果自动更新。
- 点击「应用到 N 本书」才保存，可以一次撤销或重做整批修改。预览后若任一本所选书籍发生变化，整批操作会停止，请关闭并重新打开预览。回收站条目需先恢复才能编辑。

保存和撤销现在仅重建有变化的分类关系，未修改的作者关联、书单归属日期/排序和丛书归属保持原样。

## 与其他工具交换书目

书库顶部「导入/导出」可读取 Zotero 等工具导出的 RIS 图书条目，沿用冲突预览、版本保护与撤销流程。导入提示会列出不支持的条目类型及字段；仅处理书目，不读取或下载附件。可从当前筛选结果或所选书籍导出 RIS / CSV，设置中也可导出全部未删除书籍。个人笔记需主动勾选才导出。

RIS/CSV 用于书目交换或表格查看，完整迁移仍用 JSON 备份。RIS 会合并副标题到书名，不保留阅读状态、评分、书单和原书名等应用字段；CSV 仅导出、不支持导入。详见 [支持范围、字段对照与示例](INTERCHANGE.md)。

## 网页解析器（Translators）

工具栏「从网页添加」和编辑页「从网页提取元信息…」统一使用已启用的 translator。输入网址后匹配目标、按优先级检测页面，预览后填入，最后保存。内置豆瓣与 Goodreads 适配器；普通网站可通过 JSON 规则扩展，无需重新编译，复杂布局可编写 Swift 适配器并注册。

Goodreads 示例：`https://www.goodreads.com/book/show/13634490-the-great-gatsby`。支持图书详情、首页、搜索、公开 list/show 书单和 shelf/show 分类页；不访问用户私人书架或登录账号。提取当前版本的作者、译者、出版社、出版日期、ISBN、页数、语言、简介和可选封面。缺失字段留空，不把作品首次出版日期当作当前版本出版日期。站点验证或访问限制时，可导入已保存的 HTML。

设置 → 元信息解析器 → 管理元信息解析器，可导入/导出规则、查看作者和版本、启用/停用、替换或移除自定义规则。网页解析器有独立测试入口，支持输入网址或导入已保存的 HTML，测试不写入书库。规则声明目标网页和可选封面域名，导入本身不访问网站，不执行脚本。

详见 [Translator 架构与扩展指南](TRANSLATORS.md)。[示例规则](Examples/Translators/publisher-example.json) 及配套详情/列表 HTML 可演示第二个网站的提取流程。示例使用虚构域名，仅用于本地测试。新的真实网站仍需编写和验证对应规则。

## 开发要求

- macOS 14 或更高版本
- Swift 6
- 完整版 Xcode（用于运行 macOS App 和 App Store 签名）

可先运行 `swift test` 验证模型和源码。安装 Xcode 后，打开 `Bookshelf.xcodeproj` 运行应用。

如果 `xcode-select -p` 仍指向 `CommandLineTools`，安装 Xcode 后可在 Xcode 的 Settings > Locations 中选择对应的 Command Line Tools，再进行构建。

提交 App Store 前，需要替换 Bundle Identifier、开发团队和版权信息，并将 `PRIVACY.md` 发布到可公开访问的网址后填入 App Store Connect。
