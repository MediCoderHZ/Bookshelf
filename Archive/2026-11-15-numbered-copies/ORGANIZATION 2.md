# 子书单与笔记

保持 macOS 原生 SwiftUI / SwiftData、本地书籍元信息管理的定位。行为参考 Zotero 的 [书单](https://www.zotero.org/support/collections_and_tags) 与 [笔记](https://www.zotero.org/support/notes)，不包含文件附件、阅读器或云同步。

## 书单层级

侧栏右键普通书单 →「新建子书单」。右键 →「重命名或移动」可以选择新的上级，选择「顶层书单」则移回顶层。新建或移动后自动展开当前书单的祖先。父书单默认仅显示直接加入的内容；顶部「包含子书单」可汇总后代，书籍只出现一次，不新增任何归属关系。

移除书单会同时移除其子书单及对应归属，书籍和笔记仍留在书库中，可撤销整次操作。书单不能成为自己或后代的子级，智能书单不参与普通书单树。为保持已有按名称保存的书单归属与旧备份兼容，普通书单名称仍要求全库唯一；暂不支持不同父级下的同名书单。

## 独立笔记与书籍子笔记

工具栏「新建笔记」可创建独立笔记，或为所选书籍创建子笔记。列表或封面墙中右键单本书 →「新建笔记…」，右侧编辑器会自动关联右键操作的书籍；多选和回收站书籍不显示此项。每本书可以有多条子笔记；详情面板「笔记」中可新建和查看。侧栏提供「全部笔记」「独立笔记」「笔记回收站」。

列表采用书籍与笔记的层级表格：有子笔记的书籍左侧显示展开箭头，展开后笔记缩进显示在该书下方。笔记行保留自己的标题和图标，作者、出版社等书籍字段留空。选中笔记后即可在右侧修改正文和标签，名称可选；双击或右键「编辑笔记」会将光标移到右侧正文，不打开编辑弹窗。也可将笔记移入回收站。选中笔记不会将所属书籍加入批量操作。

新建笔记会立即建立可撤销的空白条目，自动展开所属书籍并将光标放到右侧正文；搜索笔记标题、正文或标签命中时也会展开所属书籍。列排序和顶部排序菜单只改变书籍顺序，笔记始终留在所属书籍下，按创建顺序显示。折叠包含当前笔记的书籍时选择回到书籍，切换到封面墙也回到所属书籍。回收站中可展开查看随书籍保留的笔记，编辑前需先恢复书籍；单独删除的笔记仍从「笔记回收站」恢复。

笔记保存可选的自定义名称、Markdown 正文、标签、创建/修改时间。新笔记无需填写标题：列表默认取正文第一条非空内容行，去掉 Markdown 标记并最多显示 80 个字符，正文为空时显示「新笔记」。修改首行会同步更新列表名称；展开「笔记名称（可选）」可指定固定名称，清空后恢复自动命名。原有自定义标题完整保留。独立笔记可加入多个普通书单；子笔记关联一本书并随该书的书单归属显示。展开右侧「所属书籍与书单」可切换两种类型或调整归属。编辑自动保存到本机，底部显示保存状态，无需点击保存或关闭弹窗。修改和类型转换可撤销；没有实际内容变化时不产生额外历史。过期编辑器不能覆盖后来保存的版本。

顶部搜索匹配笔记标题、正文和标签，在书籍范围内也能通过子笔记找到所属书籍。高级书籍筛选中的旧「笔记」条件仍指书籍备注，新笔记请使用顶部搜索或笔记工作区。笔记标签随笔记保存和检索，目前不参与侧栏的书籍标签交集筛选。

旧版单份笔记保留在「书籍备注（原有笔记）」中；点击「转为书籍笔记并编辑」可将完整内容移动到一条子笔记并在右侧编辑，支持撤销。升级不会自动清空、拆分或重复复制旧笔记。

笔记删除后进入笔记回收站，恢复时保留关联与内容。书籍进入回收站，其子笔记随之只读隐藏；先恢复书籍即可重新查看，单独删除过的子笔记仍需恢复。永久删除书籍会一并删除其子笔记，独立笔记不受影响。合并书籍将子笔记移到主记录，撤销会恢复原关联。撤销新建书籍或书单时，若后来新增了子笔记、子书单或归属，会停止以保护这些内容。

切换条目或关闭窗口前，已经输入的修改已同步写入本地书库。发生冲突或写入失败时保留当前草稿，并尝试将恢复副本写入应用自己的 `Bookshelf/NoteDraftRecovery` 目录。底部「未保存草稿」可重新打开，选择「重试保存」或「另存为新笔记」；另存不会覆盖已有版本。恢复副本写入也失败时会明确提示，不显示为已保存。恢复草稿不属于完整 JSON 备份，需先成功保存为笔记。

笔记工作区在正在编辑的笔记不再符合筛选条件时保留该条目，并标明原因；切换后重新按筛选显示。回收站仍只读，恢复后再编辑。原生文本编辑撤销与书库操作撤销各自保留。

右侧编辑器采用原生 NSTextView / SwiftUI。可直接输入 Markdown，或选中文字后使用工具栏插入 1–6 级标题、加粗（⌘B）、斜体（⌘I）、删除线、无序/有序/任务列表、引用、链接、行内代码和代码块。「编辑／预览」在同一面板切换；预览展示格式，不改写原始正文，回收站也使用相同只读预览。每条笔记有独立的原生文本撤销栈，预览切换保留正文与光标。

当前为 Markdown 源码编辑加排版预览，不是 Zotero HTML 所见即所得编辑器。暂无表格专用排版、数学公式、图片附件或 Zotero 笔记 HTML 兼容；图片语法仅显示替代文字，不访问图片网址。预览中的原始 HTML 不执行，仅允许 http、https、mailto 链接。此功能不新增网络请求或文件管理权限。

## 备份和导入

完整 JSON 备份升级为 `schemaVersion: 4`，包含空书单、父子层级、独立笔记、书籍子笔记及其回收站状态；继续读取版本 1/2/3。旧应用不能读取版本 4。此轮不增加数据库字段或修改 JSON 键；`title` 留空代表自动命名，`body` 保留完整 Markdown 源码。含空名称的新备份应使用此版本或更新版本恢复，先前要求笔记标题非空的版本不支持。

导入预览单独列出书单与笔记，可以取消该部分。普通书单同 ID 或同名沿用本地名称和位置；同 ID 笔记保留本地内容。新笔记的书籍和书单关联会映射到导入后的实际 ID；选择将书籍另存为新记录时，子笔记跟随新记录。跳过的书籍若没有对应本地 ID，其子笔记跳过并计入结果。取消层级/笔记导入时，书籍仍按旧名称恢复普通书单归属。

导入前检查父子循环、缺失关联、重复 ID 和无效记录；书籍、书单、智能规则、笔记共用一个事务。写入失败整体回滚，导入可以整次撤销/重做；预览后相关本地记录发生变化时停止。

RIS / CSV 继续用于书籍元信息交换，「包含书籍备注」只导出旧备注字段。新笔记实体和书单层级通过 JSON 完整保存，不静默折叠进 RIS 或 CSV。

## 实现与验证

- `BookCollection.parentID` 为可空字段，旧书单自然成为顶层；新增 `LibraryNote` 实体，既有字段和默认存储路径保持兼容。
- `ManualCollectionRecord` / `NoteRecord` 为值快照；`CollectionCommands` / `NoteCommands` 处理意图，`OrganizationStore` 在 Repository 的事务中写入。
- 查询、提交后通知和撤销历史支持笔记 ID 与书单图；永久删除后清理相关撤销历史。
- `NoteEditingSession` 保留每个窗口的编辑状态，自动保存经 `NoteCommands` 提交；失败草稿由 `NoteDraftRecoveryStore` 保留，成功保存后清理恢复副本。
- 自动测试覆盖自动命名、Markdown 解析与安全链接、格式选区、原生文本撤销、无标题备份往返，以及自动保存、切换隔离、输入和光标稳定、冲突恢复、另存、撤销，以及层级循环、移动、递归查询、删除与撤销、笔记类型转换、旧备注转换、并发编辑、回收站、书籍合并、备份 ID 映射、损坏输入与持久化重开。
