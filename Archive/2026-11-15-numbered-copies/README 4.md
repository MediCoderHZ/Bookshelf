# Bookshelf

运行 `bash scripts/build-release.sh` 可检查未签名的双架构 Release 产物。

一款本地优先、使用 SwiftUI 与 SwiftData 构建的 macOS 原生书籍元信息管理器。

## 核心架构

已按 Zotero 的窗口/核心分离、数据 API、事务通知及四类 translator 机制重构。现有功能通过统一命令与数据访问层运行；编辑器和笔记有过期草稿保护，普通书单的新建/重命名可撤销。详见 [架构对照、数据流与扩展边界](ARCHITECTURE.md)。

## 当前能力

- 封面墙和列表视图
- 手动添加、编辑、移入回收站与恢复书籍
- 按书名或 ISBN 从豆瓣、Goodreads、Open Library 检索，按来源显示候选，预览后填充
- 从豆瓣或 Goodreads 的图书详情、首页等公开页面提取元信息，预览后填充（可选封面）
- 作者、译者、标签、书单和丛书数据模型
- 搜索、高级组合筛选、动态智能书单和排序
- 收藏和个人备注
- 多层子书单、移动层级、可选汇总子书单；移除层级时保留内容，支持撤销
- 独立笔记与每书多条子笔记、标签、正文检索、回收站，以及旧备注转换
- 右侧原生所见即所得笔记编辑器，Markdown 输入自动转换，格式工具直接作用于正文；标题可选，默认以首行自动命名
- 原生层级列表：书籍可展开显示下方笔记，选择笔记查看详情，排序时保持父子归属
- 将用户选择的封面复制到应用沙盒
- 保存前按 ISBN、书名和作者提示可能的重复书籍
- 包含封面和回收站状态的 JSON 备份，导入前预览冲突并选择处理方式
- 元信息逐字段对比更新、重复书籍合并、原生撤销与重做
- 多选批量编辑标签、收藏和出版信息，逐本预览后应用
- RIS 书目导入导出、CSV 清单导出，可按当前筛选或所选书籍导出，个人笔记默认排除
- 重复候选按组核对并显示原因；详情面板可查看逐字段来源，回收站支持完整只读预览
- 完整的 macOS AppIcon 尺寸集和应用内隐私政策入口
- App Sandbox 配置，仅允许用户选择的文件访问和主动发起的网络检索

## 书库整理界面

参考 Zotero 的三栏信息结构：左侧书库导航、书单与标签；中间书籍表格或封面墙；右侧可收起的详情面板。

界面会在本机记住上次选中的书单、书籍／笔记（含多选与回收站选择）、书单树和书籍子笔记的展开状态，以及右侧信息／笔记／书库与书单／标签的展开状态。重启时按当前书库验证所保存的 ID：已删除的书单回到全部书籍，不再显示的条目取消选择。搜索文字和临时筛选仍在重新打开时清空；导航偏好不写入书目或 JSON 备份。

设置 → 显示新增「界面密度」（紧凑／舒适）和「界面字号」（12、13、14、16、18 磅），即时调整书单、书籍列表、标签、笔记列表和信息面板；默认紧凑、13 磅，选择在本机保存。左侧顶部采用独立的 44 点工具栏，不显示「书库」文字；左端为文件夹加号的新建菜单，右端为查找书单的放大镜。两个按钮使用相同的 18 点线条图标和 32 点点击区域，无圆形背景或边框，与中间操作栏对齐；点击放大镜时，在同一行直接展开书单筛选框并聚焦，不增加第二行、不切换为独立结果列表；未输入关键词时，全部书籍、书单树、最近添加、状态及当前选中项保持原样。输入关键词后，在原书单树中即时筛选，始终保留「全部书籍」入口；只显示名称匹配的书单及其父级，沿用原有顺序、缩进、图标和数量，并临时展开匹配路径。带「/」的查询支持层级路径匹配，匹配父书单不会额外显示无关子书单。筛选期间隐藏最近添加及状态分组，底部重复书目、回收站和标签面板保持显示。输入文字本身不切换当前书单和中间列表；↑/↓ 选择候选，回车查看内容。点击搜索框外的书单、工具栏、其他面板或空白处后，自动收起为放大镜，同时清除临时筛选并恢复原来的展开状态；点击匹配书单会先完成定位，再收起搜索，窗口失去焦点或通过键盘移走输入焦点也会收起。点击输入框内部或清除按钮不会收起；清除关键词立即恢复完整导航和筛选前的展开状态，Esc 或点击输入框内的放大镜也可收起。搜索期间的临时展开和折叠不写入本机导航偏好。右键「查找书单」也使用同一顶部筛选框。

左侧导航区、标签区与底部筛选栏共用同一系统背景，关闭列表额外的侧栏材质，浅色和深色外观下都保持上下连续。左侧书库与书单边栏始终显示，使用原生分隔线调整宽度并记住上次位置；不提供收缩按钮、菜单或快捷键，窄窗口下同样保持可见。操作按钮与原生搜索框合并为中间列表上方的一行，滚动列表时保持可见，仅占用中间区域；窗口顶部使用紧凑的原生标题栏并保留窗口控制按钮，不再重复显示操作工具栏，右侧详情与图标栏拥有独立空间。按钮采用无底色、无边框的纯图标样式，统一尺寸与间距。按中间区域的实际宽度自动收纳：宽度至少 520 点时显示完整按钮；420–519 点时将导入/导出移入「更多」；300–419 点时保留添加、书名 / ISBN 查询和更多；更窄时仅保留更多，将其他操作收入菜单，为搜索框保留至少 140 点。拖动分隔线调整宽度时保持搜索文字和焦点；收纳不改变搜索、查询与高级筛选的快捷键，导入/导出弹窗不随工具栏收纳而关闭。搜索框右端常驻漏斗形的高级筛选按钮，清除按钮与漏斗各有独立空间。搜索框可点击清除按钮，⌘F 收起高级筛选面板并聚焦、选中搜索文字。放大镜旁的搜索范围菜单提供「全部字段」「标题」「作者」「ISBN」「标签」，默认全部字段并记住上次选择；占位提示和菜单勾选反映当前范围。切换范围保留关键词、立即更新结果，并聚焦搜索框。标题包含副标题，作者仅匹配作者，ISBN 支持连字符、空格、部分号码及等价 ISBN-10/13；标签只匹配已分配的标签名称。全部字段继续搜索书籍元信息、标签和笔记；笔记在标题 / 标签模式下仅匹配对应内容，作者 / ISBN 模式不因笔记正文而返回书籍。搜索仍与当前书单、标签筛选和回收站范围取交集。在该菜单底部点击「保存搜索为智能书单…」，可将当前字段范围和关键词保存为动态查询；直接展开中间列表上方的高级筛选面板，自动带入当前搜索范围和关键词、聚焦空白名称，并立即预览整个书库的匹配结果；填写名称后点击「保存书单」即可创建，不再弹出单独窗口。范围和关键词可继续修改，点击「搜索」刷新预览，保存后自动选中左侧新书单。查询以整个未删除书库为基础，保留快速搜索的同一匹配规则，包括副标题、等价 ISBN 和适用的笔记；不把当次结果复制为固定成员。书单标题上方显示保存的条件，可通过「编辑规则」再次修改，已有撤销 / 重做、JSON 备份恢复和重启持久化同样适用。关键词为空或处于回收站时保存入口不可用；允许保存暂时没有匹配结果的搜索。独立笔记单独显示，子笔记命中时保留所属书籍作为上下文；侧栏数量与这些结果同步。保存的搜索使用版本 2 查询结构，原有版本 1 高级规则保持兼容。搜索结果只有笔记时，笔记列表和编辑区仍分别位于中间与右侧。添加菜单包含手动录入和从网页添加；更多菜单还提供撤销、重做、列表 / 封面墙切换、整理所选和排序。当前范围由侧栏选中项表示，不显示“全部书籍”等重复范围标题；仅在有书单路径、筛选条件或重复分组时显示相关信息。

- 表格默认显示标题、副标题、作者、出版社和出版日期；右键点击任一列标题，可勾选副标题、作者、译者、条目类型、出版社、出版日期、出版年份、ISBN、语言、页数、添加日期和修改日期。表格及其列选择菜单不再提供阅读状态和评分列，原有其他列的宽度与顺序继续保留。右键菜单、整理所选、书籍操作、单本与批量编辑以及高级筛选的字段菜单也移除阅读状态和评分；常用条件中的「尚未评分」「高分书籍」一并移除，排序菜单与 CSV 导出不再提供评分。标题列始终显示书籍或笔记的标题，副标题默认紧随其后；笔记行的副标题留空。拖动表头两列之间的竖线，可独立调整该列宽度，向左右拖动即可缩窄或加宽；双击列右侧分隔线，按当前结果中该列的表头和最长内容自动适配宽度，包含滚动区域外的书籍及已展开笔记，预留标题图标、收藏星标和层级缩进；折叠笔记不参与计算。自动适配后的列宽同样保存；标题最窄 80 点，其余列最窄 40 点，不设最大宽度。内容过长时在单元格内截断，列总宽超出中间面板时可水平滚动，不覆盖右侧详情。列宽、显示状态与顺序自动保存，重新启动后恢复，已有自定义设置继续保留。点击列标题排序，页数按数值、添加与修改日期按实际时间排序，笔记保持在所属书籍下方；笔记的日期列显示自身时间。右侧信息面板直接显示副标题字段，可点击编辑并自动保存。双击条目编辑。
- 表格支持 Command 多选和 Shift 连选；封面墙支持 Command 多选。右键或「更多操作 → 整理所选」可批量设置收藏和书单归属。
- 侧栏顶部依次显示「全部书籍」「重复书目」「回收站」，下面接普通书单和自建智能书单，顶层项目保持同级。三项导航与书单共用同一滚动列表；「回收站」与自建书单之间显示一条系统细分隔线，细线利用条目之间已有的内边距，不单独占用一行；普通导航行保持原有高度，颜色随浅色／深色外观变化，分隔线不可选中；没有书单时不显示。不再在标签面板上方重复固定入口，也不显示「状态」分组、「最近添加」或默认的书籍类型智能书单。旧版保存的状态、最近添加或已移除智能书单选择，在启动时回到「全部书籍」。
- 点击「回收站」统一显示已删除的书籍和笔记，侧栏数量包含两者；单独删除的子笔记和独立笔记直接显示为笔记条目，随书籍进入回收站的笔记保留在书籍下方。回收站始终使用列表，支持 ⌘ 点选多项、⇧ 连续选择和书籍/笔记混合选择；通过右键、详情面板或「更多操作 → 整理所选」可批量恢复或永久删除。所属书籍也被删除时，需同时选中书籍或先恢复书籍。进入回收站会清除之前的搜索和筛选。侧栏「回收站」右键菜单仅显示「清空回收站…」，为空时禁用，执行前仍需确认。已有的删除标记无需迁移，历史删除笔记会直接显示。
- 左侧导航共用统一行样式：16 点线条图标占据 20 点图标列，与文字间距 8 点；书库、普通/智能书单、重复书目和回收站统一行高、内边距及右侧数量排版，子书单保留原生层级缩进。
- 左侧导航空白处和条目均支持右键菜单：查找书单、新建普通/智能书单、展开/折叠全部书单、显示条目数量及包含子书单；数量显示设置会保存。查找支持名称和层级路径，回车或双击可前往并展开祖先书单。右键普通书单、智能书单时，先显示对应管理操作；回收站右键仅显示「清空回收站…」；操作针对右键命中的条目，空白处不提供移除操作。标签保留独立的重命名/删除菜单。
- 右键侧栏空白处或「全部书籍」，可选择「新建书单」或「新建智能书单」；左侧顶部的文件夹加号菜单也保留这些入口。新建普通书单默认位于三项书库导航下方，与其平级；右键普通书单可新建子书单、重命名或移动层级。同一本书可加入多个书单；「从当前书单移除」只解除该书单归属。父级默认不汇总后代，可勾选「包含子书单」。
- 中间列表支持将书籍拖到左侧普通书单或子书单；先用 ⌘ 或 ⇧ 多选，再拖动任一选中书籍，即可整批加入。目标行在悬停时高亮；保留原书单归属，不复制书籍，重复拖入自动跳过已有归属。整批自动保存，可一次撤销/重做。笔记、回收站条目不能作为来源，智能书单、重复书目与回收站不接受拖入；放下后若书籍或书单已失效，整批停止并提示。
- 左侧书单支持拖动排序：拖到书单行的上/下边缘显示插入线，调整同级顺序；拖到普通书单中央成为其子书单，并自动展开目标层级；拖到「全部书籍」移回顶层末尾。普通与智能书单可混合调整顶层顺序，智能书单仅保留在顶层。移动整个书单子树时保留书籍和笔记归属，禁止循环层级，放下后统一自动保存并支持一次撤销/重做；顺序随数据库及完整备份保存，旧备份仍兼容。
- 拖动书籍（含多选）或普通书单时，悬停在折叠书单上约 0.65 秒会自动展开，可逐级进入子书单。拖动书单时仅在行中央触发展开，上下边缘仍用于排序；快速经过、移开、放下或取消拖动不会触发延迟展开。悬停只展开导航，不改变当前选择或书籍归属，实际放下后才保存变更。
- 侧栏标签以紧凑文字自动换行排列，不显示「标签」标题、逐项图标和数量；数量与完整名称保留在悬停提示中。点击标签可多选，选中项高亮，保留重命名、删除和合并的右键操作。
- 标签筛选框固定在面板底部，不随标签滚动。默认只显示中间当前书籍结果使用的标签，随普通/智能书单、包含子书单设置、阅读分类、书库搜索和组合筛选更新；回收站使用其自身的书籍范围。悬停数量对应当前结果，不是全库数量。
- 底部筛选菜单提供「显示全部标签」开关并记住设置：开启后显示全库标签，当前范围未使用的标签以灰色显示，标签名称搜索仍然生效。菜单也可清除已选标签或搜索文字。
- 切换书单或分类时清除旧的标签筛选；同一范围内搜索、编辑或多选造成零结果时，已选标签仍保留以便取消。多选继续使用交集筛选，并与当前书单和书库搜索共同生效。
- 左侧书单区域和右侧详情面板的竖向分隔线支持原生拖动，分别保存松开时的宽度，重启后恢复；收起面板和调整窗口大小不会覆盖已保存的宽度。左侧可在 200–400 点、右侧可在 290–600 点之间调整，中间书籍列表保留至少 360 点，实际可调范围受窗口大小限制。
- 标签面板上方的分隔线可上下拖动，实时调整面板高度；松开后保存高度，重新打开应用或侧栏时恢复。上方导航和标签面板均保留最小可用高度，窗口变小时仅限制当前显示，不覆盖已保存的高度；分隔线也支持辅助功能的增减调整。
- 侧栏标签右键可重命名或删除。输入已有标签名称时会显示合并范围，点击「合并标签」后合并关联并去重；重命名保留标签标识，合并沿用目标标签。操作同步处理书籍与同名笔记标签（含回收站）；删除仅移除标签及关联，保留书籍与笔记。支持撤销/重做，预览后数据变更或撤销时名称被重新使用会停止操作，避免覆盖新内容。
- 详情面板独立「标签」区块的标题旁显示当前标签数量，默认仅显示已有标签；点击标题旁的加号才展开并聚焦输入框，添加成功后收起，增删后数量实时更新。回收站显示数量和已有标签，不提供添加入口。输入框会匹配已有标签，优先显示完整匹配和前缀匹配，也支持关键词包含匹配；忽略大小写、全半角及重音差异。点击候选直接添加，也可用 ↑/↓ 高亮选择候选并按回车添加，长列表会随选择滚动。当前书籍已有的标签标记为「已添加」，键盘选择会跳过它们。Esc 关闭候选列表并保留输入；继续输入或按 ↑/↓ 可重新展开。候选关闭后再次按 Esc 取消输入并收起输入框。未选择候选时，回车或点击加号仍可添加输入的新标签，完整匹配已有名称时沿用原名称；中文输入法组词期间不截获候选选择及确认按键。
- 右侧详情面板采用无封面的紧凑布局：顶部只显示书名和「书籍操作」菜单，底部不再常驻编辑/删除按钮。正文分为可折叠的「信息」「笔记」「书库与书单」「标签」，默认展开信息，中间列表与详情使用原生分割面板并排排版，拥有独立的不透明背景和裁切边界，列表内容不会延伸到详情区域；列表操作栏背景常驻，搜索框与详情正文互不遮挡。右侧纵向图标栏固定在窗口最右侧，独立于详情内容；未选条目、多选、笔记编辑、空书单与收起详情面板时仍保持显示，滚动正文不会移动图标栏。顶部开关收起或展开详情内容，保留 ⌥⌘I；点击可用分区图标会展开详情并定位对应内容，不可用图标灰显。选择笔记时仅笔记图标可用，笔记工作区也可通过同一开关收起编辑区。元信息按字段名/值对齐，当前类型适用的空白字段保留并可直接填写；信息区不再显示简介及其添加入口，添加日期和修改日期紧接其他信息字段排列，共用字段标签宽度、字体和行距，显示日期和具体时间；书库与书单仅显示当前书籍的实际归属及父级路径，父级以浅色显示，直接归属的书单可点击定位到左侧；多个归属共享父级时只显示一次。点击位置会清除搜索/筛选、展开左侧父级，并保留当前书籍选中状态；未加入书单时只显示「我的书库」。「书库与书单」标题旁始终显示加号，菜单列出已有普通书单的完整路径，勾选加入、取消勾选移除；没有普通书单时提示在左侧新建。所属书单行旁的减号也可移除当前归属，只解除该书单关联，保留书籍、笔记和其他归属；用于展示路径的祖先行不显示移除按钮。修改后自动保存并展开归属区块，支持撤销/重做；回收站不显示加号或移除按钮。标签在独立区块增删。收藏从书名旁的「书籍操作」菜单修改。更多编辑选项、收藏与删除从书名旁菜单进入；回收站只读并提供恢复/永久删除菜单。笔记编辑仍在右侧直接进行并自动保存到本机。
- 条目类型仅有「中文原版书」「英文原版书」「中文译本」。手动新建默认中文原版书；右侧顶部可直接切换，自动保存并可撤销。原版书默认只显示作者，中文译本显示作者和译者（可留空），「原书名」和「原作语言」仅在中文译本中显示，空值留白；中文原版书、英文原版书及未设置类型的条目均隐藏这两个字段，已有值也不例外。右侧信息面板和编辑表单使用同一规则。切换类型只改变字段显示，不删除译者或原作信息；切回中文译本后可继续编辑。类型不会覆盖已有语言字段。旧书库及来源不明确的导入记录保留未设置值，信息面板中的类型值保持空白，点击后菜单仍仅有三个选项；不根据书名文字、国籍、语言或译者缺失猜测类型。在线添加书籍在保存前需选择类型。高级筛选支持条目类型及其是否为空，可保存为智能书单；类型和原作语言进入字段来源、合并、备份恢复及书目交换。
- 书名、作者、出版社、出版日期、ISBN 等元信息可直接点击编辑，回车、Tab 或离开字段时自动保存，Esc 取消当前修改；信息面板直接显示当前条目类型适用的全部字段，不再提供「添加字段」入口；空值保持留白，仍可点击填写，不使用破折号占位。作者和译者采用完整的逐人元信息行：每行重复角色标签并与其他字段对齐，默认只显示标签和姓名；鼠标移到姓名区域才显示圆圈减号、圆圈加号和更多图标，移开后隐藏（VoiceOver 开启时保留可访问的操作）。加号在当前行下方插入一位作者／译者，减号删除当前行，更多菜单支持上移、下移和移至首尾。人数超过五位时默认折叠其余姓名，可点击“还有 N 位…”展开或收起；空列表点击姓名留白区域或悬停后的加号开始填写，不再显示单独的“添加作者”说明行。姓名中的标点原样保留。输入时匹配正常书库中已使用的姓名，优先完整/前缀匹配，同等匹配优先当前角色和常用姓名；大小写、全半角及重音差异不影响匹配，候选保留已有写法。↑/↓ 选择候选，回车或点击候选填入当前行并自动保存；候选超过五行时可滚动。未选候选仍可直接保存新姓名；Esc 先关闭候选，再按一次取消本行修改。中文输入法组词时不拦截方向键、回车或 Esc。回车、Tab 或离开姓名自动保存，增删与排序立即保存，均可撤销/重做。Esc 取消本行修改；未填写姓名的新行不会写入书库。出版社同样匹配正常书库中已使用的名称，完整和前缀匹配优先，同等匹配优先常用出版社；支持 ↑/↓、回车或点击填入并自动保存，Esc 关闭候选，仍可自由输入新出版社。已有简介数据仍保留在书库中，导入与导出继续兼容。ISBN 和页数会校验，失败时保留输入并在字段下提示；切换书籍或重新启动后可找回未保存的输入。每次字段修改可撤销，只更新该字段并标记为手动编辑；同一字段被其他操作修改时提示冲突。
- 工具栏魔棒按钮或 Shift-Command-I 打开书名 / ISBN 检索；Option-Command-I 显示或隐藏详情面板。

搜索入口默认查询全部已启用来源，也可选择单站。各来源独立加载并显示失败原因；点选候选后读取具体版本的详情。ISBN 缺失或与查询不符会提示核对，ISBN-10 与对应 ISBN-13 视为同一号码。封面默认不下载，可在预览中勾选。设置里停用豆瓣、Goodreads 或 Open Library 后，该来源停止参与搜索。RIS / CSV 也通过同一设置管理。
- 在当前书单内点击工具栏「添加书籍」，新书会预选该书单；编辑已有书籍会保留其全部书单归属。

## 安全整理与更新

- 设置 → 从备份恢复：先预览新增与冲突，逐条选择跳过、添加为新记录、补全空白或采用导入的出版信息。冲突默认跳过；不同有效 ISBN 的版本不能互相覆盖。更新会汇总笔记、标签和书单。
- 删除只移入侧栏「回收站」，保留元信息、笔记、分类和封面；可批量恢复书籍和笔记，整批恢复可一次撤销/重做。永久删除和清空前均显示确认框，列出实际涉及的书籍/笔记数量（子笔记只计一次），并说明不可撤销；取消不改变数据。侧栏「回收站」右键和回收站内「更多操作」均提供「清空回收站…」，统一删除全部已删除书籍及笔记，包括搜索筛选未显示的条目，正常在库内容保留。确认后条目被修改、恢复、移除或新增关联子笔记时停止整批删除；清空期间回收站范围变化也需重新确认。
- 搜索或网页提取后显示字段对比，默认仅勾选空白字段；未提供的值不会清空已有内容，封面也可单独选择。应用字段后仍需在编辑页保存。
- 侧栏「重复书目」显示可能重复的记录。选择两本以上 → 整理所选 → 合并，选择主记录与各字段来源；汇总笔记、标签、书单、丛书，其他原记录移入回收站。ISBN-10 与对应 ISBN-13 视为同一版本；不同有效 ISBN 不允许合并。
- 本次窗口会话中，添加、编辑、导入、整理、移入回收站、恢复和合并支持「编辑 → 撤销/重做」。输入框聚焦时快捷键优先撤销文字输入，书库顶部「更多操作」也提供撤销和重做。退出后撤销历史不保留，回收站仍保留。如果记录在操作后发生了未追踪的修改，撤销会停止以免覆盖新内容。
- 新备份格式为 schemaVersion 7，可读取旧版 1/2/3/4/5/6；旧版应用不能读取新格式。备份包含回收站、字段来源、智能条件、空书单与父子层级、独立笔记和子笔记。导入预览可核对并取消书单/笔记部分，同 ID 笔记保留本地；自定义解析规则仍需另行导出。

## 子书单与独立笔记

工具栏「新建笔记」支持独立笔记和书籍子笔记；顶部搜索可检索笔记标题、正文与标签，独立笔记显示在全部书籍或所属书单中。书籍详情的「笔记」标题旁显示数量和新建加号；区块内仅显示已有笔记的标题行，点击打开正文，不再重复显示「书籍笔记」标题、新建按钮或空白说明。点击加号直接在右侧新建并编辑子笔记，数量随新建、移入回收站及恢复同步更新。单独删除的笔记不计入数量；原有单份笔记作为书籍备注保留并计为一条，可一键转为子笔记并撤销。回收站内显示保留的笔记及数量，不提供新建入口。

笔记使用右侧原生所见即所得编辑器，输入 Markdown 语法后直接显示格式，工具栏直接修改正文，输入后自动保存；新建和编辑均无单独弹窗。无需填写标题，列表默认以正文首行命名。笔记面板仅显示格式工具栏和正文，铺满右侧区域；名称、标签、归属设置和常驻保存状态均不显示。保存失败时显示提示并保留草稿，可重试或另存；笔记条目右键可移入回收站。书籍合并和撤销会同步处理子笔记关联。详见 [操作说明、备份规则与限制](ORGANIZATION.md)。

在「重复书目」中使用「重复组」选择器，自动选中一组并显示匹配原因：ISBN 相同、书名与作者关联，或仅书名相同。缺少有效 ISBN 的记录可能把不同版本关联在一起，此时会提示先核对并禁用整组合并；已知的不同 ISBN 不会直接视为重复。选择分组会清除搜索与标签筛选，之后增加筛选时需清除筛选再整组合并。识别使用索引分组，避免逐本扫描整库。

右侧详情面板显示信息、笔记、书库与书单和标签分区；回收站展示原有书单路径与标签，恢复前只读。来源区块及其导航图标不再显示。来源记录仍随元信息保存，供更新、合并预览与备份使用；新提取的信息记录逐字段来源，手动修改仅把对应字段标记为手动编辑，旧记录的整体来源不会当成已核实的逐字段来源。回收站内恢复前保持只读。

书库顶部「更多操作」菜单显示撤销、重做及操作名称；设置中的备份区域保留撤销、重做按钮。无可用历史时对应操作禁用。设置与书库窗口分别保留各自的操作历史。

## 高级筛选与智能书单

点击搜索框右端的漏斗按钮或按 Option-Command-F，在中间书籍列表上方展开高级筛选面板，不再弹出独立编辑窗口。工具栏显示「高级筛选」标题和 × 关闭按钮，不再提供缩放按钮或独立的收起功能。点击 × 关闭普通筛选面板后恢复顶部搜索框，保留已应用结果和普通筛选条件草稿；编辑智能书单时，× 用于取消未保存的编辑。点击漏斗可重新展开普通筛选面板，漏斗以强调色表示存在已应用的高级筛选。条件由字段、比较方式和值组成，支持全部／任一条件，每行加减号添加或移除条件（最多 50 条）。可以组合标题、作者、译者、出版社、出版年份、ISBN、语言、标签、普通书单、页数、笔记、元信息来源、封面和收藏条件；标题同时匹配副标题和原书名。窄窗口自动将条件值放到下一行，多条件区域独立滚动。编辑草稿不立即更改结果，点击「搜索」或在条件值中按回车后更新下方列表；「清空」重置条件并恢复全部书籍，空条件值不作为有效筛选。

面板的更多菜单中，「常用条件」提供待补全 ISBN 和有笔记的书。年份按当前版本出版日期的四位年份筛选。数值未知时不会匹配数值比较，请用「为空」查找缺失信息。文本忽略大小写、全半角与音调，ISBN 等值比较识别对应的 ISBN-10/13。

应用高级筛选会从全部未删除书籍开始，并清除当前搜索与标签条件。之后可叠加顶部搜索、标签和侧栏分类；切换智能书单会清除临时筛选，回收站不应用高级筛选。

点击面板中的「保存搜索…」，直接在同一个面板显示并聚焦空白名称框，完整保留当前草稿中的匹配方式、全部条件及尚未应用的修改，并预览这些条件在整个书库中的结果。填写名称后点击「保存书单」创建并自动选中新书单，不再弹出命名窗口。收起面板后，结果摘要中的「保存为智能书单…」也会展开同一面板并带入已应用的条件；侧栏右键菜单或左侧顶部的文件夹加号菜单中的「新建智能书单」也直接展开该面板，自动切到全部书籍并聚焦空白名称，只预置一条空白条件，不继承其他书单或筛选的规则。填写名称和条件后可先「搜索」预览，再点击「保存书单」创建并选中左侧新书单；取消、点击 × 关闭、⌘F 或切换范围会放弃草稿，不生成空书单。空白名称或无效条件不可保存；同名错误在面板内显示并保留输入。创建后仍支持撤销/重做。智能书单保存筛选条件，随书籍信息变化自动更新，不复制记录，也无需手动加入书籍。点击结果上方或侧栏右键菜单的「编辑规则」，直接在同一个高级筛选面板中载入书单名称、匹配方式和已有条件，不再打开规则编辑弹窗。从搜索框保存的智能书单保留原有范围、关键词及笔记匹配语义，也可添加附加条件。「搜索」在整个书库中预览新规则，保持左侧书单选中，不与旧规则取交集；预览期间书单定义和侧栏数量仍按已保存规则显示。点击「保存修改」更新当前书单，保留标识、创建时间和排序，结果随规则更新；「取消」、点击 × 关闭、⌘F 或切换到其他书单会放弃未保存的编辑及预览。名称与规则校验失败时保留草稿并显示原因；若书单被其他操作更改或删除，保存会拒绝覆盖，可取消后重新编辑。侧栏右键仍可移除智能书单，移除只删除定义，书籍仍保留。创建、编辑和移除支持当前窗口的撤销/重做，规则随 JSON 备份导出，纯智能书单备份也能导入。

不再自动创建「中文原版书」「英文原版书」「中文译本」智能书单。升级时按本地书库执行一次清理：仅在旧初始化标记存在时，移除仍使用默认名称（含旧名称冲突后缀）和完整单条类型规则的预设；改过名称或规则的书单、自建其他查询和普通书单保留。旧版未记录每条预设的来源，因此名称与规则完全相同的定义按默认项处理；移除前将完整定义保存在该书库对应的本机偏好备份中。完成后不会再次清理用户后来创建的同名同规则书单。书籍的条目类型、笔记和普通书单归属保持不变；仍可通过高级筛选自行保存类型查询。

阅读状态和评分功能已完全移除。打开旧书库时，自动迁移删除阅读状态、开始阅读日期、完成阅读日期和个人评分字段，并清理智能书单中的状态与评分条件：仅含这两种旧条件的智能书单移除，混合条件书单保留其余规则及匹配方式，已保存的搜索关键词和范围保留。旧状态导航及状态、评分表格列偏好一并清理，其他列宽、顺序和导航设置保留。导入旧 JSON 备份时同样丢弃这些字段和条件，新备份不再包含它们。

## 批量编辑

在列表或封面墙中多选书籍，点击右侧「批量编辑…」，或从「整理所选」/右键菜单进入「批量编辑标签与信息…」。默认所有字段保持原样；右侧列出所选书籍及每本的修改数量，点选即可查看当前值与修改后的值。

- 出版社、出版日期、版次、语言支持「保持原样」「仅补空白」「替换为」「清空」。仅补空白保留已有内容；填写空字符串不能代替清空。
- 可统一加入或取消收藏。
- 标签可批量添加、从现有标签中选择，或勾选从所选书籍移除的标签；标签旁显示在所选书籍中的使用数量。忽略大小写、全半角和音调进行去重，同一标签不能同时添加和移除。其他标签以及未选中的书籍保持原样。
- 没有实际差异的书籍不写入，也不改变修改时间。实际修改的出版字段标记为「手动编辑」，其他字段来源、个人笔记、作者、书单和丛书保留。智能书单随修改结果自动更新。
- 点击「应用到 N 本书」才保存，可以一次撤销或重做整批修改。预览后若任一本所选书籍发生变化，整批操作会停止，请关闭并重新打开预览。回收站条目需先恢复才能编辑。

保存和撤销现在仅重建有变化的分类关系，未修改的作者关联、书单归属日期/排序和丛书归属保持原样。

## 与其他工具交换书目

书库顶部「导入/导出」可读取 Zotero 等工具导出的 RIS 图书条目，沿用冲突预览、版本保护与撤销流程。导入提示会列出不支持的条目类型及字段；仅处理书目，不读取或下载附件。可从当前筛选结果或所选书籍导出 RIS / CSV，设置中也可导出全部未删除书籍。个人笔记需主动勾选才导出。

RIS/CSV 用于书目交换或表格查看，完整迁移仍用 JSON 备份。RIS 会合并副标题到书名，不保留书单和原书名等应用字段；CSV 仅导出、不支持导入。详见 [支持范围、字段对照与示例](INTERCHANGE.md)。

## 网页解析器（Translators）

工具栏「添加书籍 → 从网页添加」和编辑页「从网页提取元信息…」统一使用已启用的 translator。输入网址后匹配目标、按优先级检测页面，预览后填入，最后保存。内置豆瓣与 Goodreads 适配器；普通网站可通过 JSON 规则扩展，无需重新编译，复杂布局可编写 Swift 适配器并注册。

Goodreads 示例：`https://www.goodreads.com/book/show/13634490-the-great-gatsby`。支持图书详情、首页、搜索、公开 list/show 书单和 shelf/show 分类页；不访问用户私人书架或登录账号。提取当前版本的作者、译者、出版社、出版日期、ISBN、页数、语言、简介和可选封面。缺失字段留空，不把作品首次出版日期当作当前版本出版日期。站点验证或访问限制时，可导入已保存的 HTML。

设置 → 元信息解析器 → 管理元信息解析器，可导入/导出规则、查看作者和版本、启用/停用、替换或移除自定义规则。网页解析器有独立测试入口，支持输入网址或导入已保存的 HTML，测试不写入书库。规则声明目标网页和可选封面域名，导入本身不访问网站，不执行脚本。

详见 [Translator 架构与扩展指南](TRANSLATORS.md)。[示例规则](Examples/Translators/publisher-example.json) 及配套详情/列表 HTML 可演示第二个网站的提取流程。示例使用虚构域名，仅用于本地测试。新的真实网站仍需编写和验证对应规则。

## 开发要求

- macOS 14 或更高版本
- Swift 6
- 完整版 Xcode（用于运行 macOS App）

可先运行 `swift test` 验证模型和源码。安装 Xcode 后，打开 `Bookshelf.xcodeproj` 运行应用。

如果 `xcode-select -p` 仍指向 `CommandLineTools`，安装 Xcode 后可在 Xcode 的 Settings > Locations 中选择对应的 Command Line Tools，再进行构建。
