# 书目交换

书库顶部「导入/导出」可导入 RIS，或把当前筛选结果、所选书籍导出为 RIS / CSV。设置 → 书目交换可导出全部未删除书籍。所有操作均在本机进行，导出到用户选择的位置。

## 从 Zotero 等工具迁入

在来源工具中把图书条目导出为 RIS，再在本应用选择「导入 RIS 书目…」。本应用支持 UTF-8（可带 BOM）及带 BOM 的 UTF-16；单次最多 10 MB、5000 条。支持 BOOK、EBOOK、EDBOOK、CLSWK 和 SER 类型的整本图书。文章、章节和无书名记录会跳过并在预览中提示，不会转成整本书。

预览显示可导入数量、跳过条目、未支持字段及同库/文件内重复。冲突默认保留本地，可逐条选择新增、补全或更新；不同有效 ISBN 的版本不能覆盖。导入后可在执行导入的窗口撤销或重做。预览期间修改了目标记录时，更新会停止，请重新打开预览。

每条记录需要 TY 开始和 ER 结束。截断、结构不完整、编码错误和超限文件会拒绝整份导入，不会先写入部分条目。单值字段重复时采用首个值并提示；日期优先 DA，其次 Y1、PY。多个不同 ISBN 只采用首个有效版本，等价 ISBN-10/13 可以同时保留。无法识别的 ISBN 和非整数页数留空并提示。

| RIS 字段 | 本应用字段 |
| --- | --- |
| TI / T1 | 书名 |
| AU / A1；A4；A2 / A3 | 作者；译者；编辑 |
| PB；DA / Y1 / PY；ET；LA | 出版社；出版日期；版次；语言 |
| SN；SP | ISBN；页数（仅整本书的单一整数） |
| AB / N2；N1 / RN；KW | 简介；个人笔记；标签 |
| T2 / T3；VL | 首个丛书；册号 |
| UR | 普通 HTTP(S) 来源网址，不接受账户凭据 |

来源明确标记为「RIS 文件导入」，导入时间不代表网站抓取时间。姓名按文件中的写法保留，不自动颠倒西文姓名；每条 KW 作为一个标签。多行简介和笔记按纯文本保存，HTML 标记也作为文字，不执行脚本。附件字段（例如 L1/L2）、未知字段只提示，不访问文件或网址、不下载封面。

## 导出格式与范围

导出窗口列出范围与书籍数量；当前结果包含搜索、标签、分类和高级筛选共同筛出的书籍，所选仅导出选中条目。回收站始终排除。导出使用打开窗口时的书目快照。

- **RIS**：条目类型和原作语言使用带 `Bookshelf.` 标识的 C1/C2 扩展字段，保留 `TY=BOOK`；本应用可往返恢复，其他工具可能忽略这两个字段。导出出版字段、作者/译者/编辑、标签、简介、普通来源网址和首个丛书。副标题合并到书名。原书名、其他贡献者、普通文件夹及逐字段历史来源不在 RIS 中。多行内容以缩进续行输出，避免文字被误当成新记录。
- **CSV**：UTF-8、带 BOM 的逗号分隔清单，包含条目类型、原作语言、书名、副标题、原书名、作者、译者、出版社、日期、版次、ISBN、页数、语言、简介、标签、普通文件夹和来源网址。不再导出阅读状态、评分或收藏列；JSON 备份同样不再包含阅读状态、个人评分、收藏及开始、完成阅读日期；导入旧备份时会丢弃这些字段，并移除状态、评分与收藏筛选条件；仅含这些旧条件的智能文件夹移除，混合文件夹保留其他条件。双引号、逗号和换行按 CSV 转义；ISBN 和可能被识别为公式的文本加单引号前缀。部分表格软件会显示此前缀，可将列按文本导入。本版本只导出 CSV，不提供 CSV 导入或任意列映射。
- **书籍备注**：两种格式默认均不包含旧版单份备注；勾选「包含书籍备注」后才写入。新建的独立笔记和书籍子笔记不折叠进此字段，通过 JSON 备份完整保存。

RIS/CSV 不包含新笔记实体、文件夹层级、回收站和智能文件夹定义，不用于完整恢复。完整迁移、回滚和保留历史来源请使用 schemaVersion 9 JSON 备份；自定义网页解析器仍单独导出。RIS 的 N1/RN 仍导入书籍备注，可在详情中显式转为子笔记。

## 示例与验证依据

[自制 RIS 样例](../Examples/Interchange/sample-books.ris) 包含一条虚构图书和一条会被跳过的文章，用于演示字段和提示，不连接示例网址。回归测试使用自制数据，覆盖编码、续行、类型跳过、损坏文件拒绝、ISBN、字段往返、CSV 转义、冲突及撤销。

Zotero 支持 RIS 导入：[官方说明](https://www.zotero.org/support/kb/importing_standardized_formats)。字段对照参考其 [RIS translator 的公开映射](https://github.com/zotero/translators/blob/master/RIS.js)，本项目独立实现 Swift 读写器，不打包或执行 Zotero 脚本；并未宣称所有 RIS 方言均兼容。CSV 引号规则参考 [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.html)，公式前缀处理参考 [OWASP 说明](https://owasp.org/www-community/attacks/CSV_Injection)。

条目类型 C1 值为 `Bookshelf.BookType=chineseOriginal`、`Bookshelf.BookType=englishOriginal` 或 `Bookshelf.BookType=chineseTranslation`；原作语言 C2 为 `Bookshelf.OriginalLanguage=` 加原始文本。没有这些扩展的外部书目保持类型未设置；其他应用的 C1/C2 值只提示，不当作本应用分类。JSON 版本 1–7 缺少新增字段时仍可恢复，已有人员及语言信息完整保留。
