# 子文件夹与笔记

保持 macOS 原生 SwiftUI / SwiftData、本地书籍元信息管理的定位。行为参考 Zotero 的 [文件夹](https://www.zotero.org/support/collections_and_tags) 与 [笔记](https://www.zotero.org/support/notes)，不包含文件附件、阅读器或云同步。

## 文件夹层级

侧栏顶部依次显示「全部书籍」「重复书目」「回收站」；普通文件夹和自建智能文件夹显示在这三项下方，以一条细分隔线区分书库导航和文件夹区域；细线利用条目之间已有的内边距，不再额外占用一行；普通导航行保持原有高度。分隔线不参与选择，没有文件夹时隐藏。顶层项目保持同级，不再单独显示「文件夹」分组。右键侧栏空白处或「全部书籍」可新建普通或智能文件夹，默认新建顶层文件夹；左侧顶部的文件夹加号菜单也提供这两个新建入口，放大镜直接在顶部同一行展开筛选框，不替换侧栏内容；空关键词保留完整导航、选中项和展开状态。输入后在原文件夹树中筛选，保留三项书库导航入口，只显示名称匹配的文件夹及其父级，并按原有顺序和缩进展开匹配路径；带「/」可匹配层级路径。输入本身不改变当前文件夹内容，↑/↓ 选择候选，回车或点击文件夹查看内容。清空恢复全部导航和原来的展开状态；点击搜索框外的文件夹、按钮、面板或空白处时自动收起为放大镜并清除临时筛选，文件夹点击会先定位再收起。窗口或键盘输入焦点离开时也自动收起，输入框内点击和清除按钮保持展开；Esc 或再次点击放大镜仍可收起，搜索中的展开／折叠不写入导航偏好。顶部不再显示「书库」文字。侧栏右键普通文件夹 →「新建子文件夹」。右键 →「重命名或移动」可以选择新的上级，选择「顶层文件夹」则移回顶层。新建或移动后自动展开当前文件夹的祖先。父文件夹默认仅显示直接加入的内容；顶部「包含子文件夹」可汇总后代，书籍只出现一次，不新增任何归属关系。

中间原生表格支持单本和多选书籍拖入左侧普通文件夹（含子文件夹），使用加入语义，保留原有归属。目标行高亮，来源不包含笔记或回收站条目，智能文件夹不接收手动拖入。拖放数据仅包含本次书库会话标识和书籍 ID；放下后一次读取整批数据、重新验证书籍及文件夹，统一提交并注册一次撤销。已有归属跳过，不复制条目或重复创建关系；其他书库、失效条目、回收站记录及不支持的数据均不写入。

文件夹行可拖动：上、下边缘为同级插入位置，中央为移入普通文件夹；「全部书籍」接收拖回顶层。顶层普通与智能文件夹按保存的顺序共同排列，智能文件夹不能作为父文件夹或成为子文件夹。移动父文件夹保留整个后代树、归属关系及其 ID。`CollectionOrdering` 生成受影响同级的顺序调整，`CollectionCommands.move` 验证会话、源记录和目标层级后通过同一事务提交，并为普通及智能文件夹注册一次撤销。使用既有 `BookCollection.sortOrder` 字段；记录、撤销和备份均携带顺序，旧备份缺省为 0 并保留原先普通文件夹优先、名称排序的显示方式。新建和通过编辑器更换上级时追加到目标同级末尾，重命名不改变位置。

拖放目标行使用 `SidebarDragHoverExpansion` 管理 650 毫秒的悬停展开，普通文件夹和书籍拖动共用目标处理器。定时器注册到主运行循环的 common modes，原生拖动跟踪期间也可触发；重复更新不重置延迟，离开、落下、行消失或身份变化时取消，代次标识阻止已排队的旧回调误触发。触发前重新检查折叠状态、鼠标按下状态及文件夹层级有效性。文件夹排序边缘不触发展开，允许有效但位置不变的父文件夹展开以进入其子级；自身、后代与智能文件夹等无效目标不会展开。悬停只改变展开集合，不修改选中项、归属或数据库。

移除文件夹会同时移除其子文件夹及对应归属，书籍和笔记仍留在书库中，可撤销整次操作。文件夹不能成为自己或后代的子级，智能文件夹不参与普通文件夹树。为保持已有按名称保存的文件夹归属与旧备份兼容，普通文件夹名称仍要求全库唯一；暂不支持不同父级下的同名文件夹。

详情面板「书库与文件夹」标题旁的加号菜单列出已有普通文件夹及其完整路径，勾选加入、取消勾选移除；空文件夹库仍显示加号，菜单提示先在左侧新建。实际所属文件夹行旁提供减号按钮，移除只解除当前归属，不删除书籍、子笔记或其他归属。路径中的非归属祖先行不提供移除按钮；智能文件夹按规则自动计算，不列入手动归属菜单。修改自动保存、展开归属区块并支持撤销/重做，点击文件夹名称仍可在左侧定位；回收站仅展示归属。

侧栏移除「状态」分组和「最近添加」入口；已有书籍状态仍可在信息面板和高级筛选中使用。启动时不再创建三种书籍类型的默认智能文件夹。旧初始化标记存在的本地书库执行一次清理，匹配原名称（含名称冲突后缀）及完整类型规则；重命名或改过规则的文件夹保留。清理前在本机偏好中按书库位置备份完整定义，成功提交后标记完成，不影响书籍、笔记与普通文件夹归属，也不会重复清理后来新建的类型查询。旧版本没有逐项来源标识，完全同名同规则的查询按默认项处理。已撤掉的侧栏范围在恢复导航状态时回到「全部书籍」。

## 独立笔记与书籍子笔记

独立笔记可直接拖到中间表格的书籍行上，转为该书的子笔记并自动展开；子笔记也可拖到其他书籍重新归属。按 ⌘ 或 ⇧ 可多选笔记，从任意一条选中的笔记开始拖动即可整批移动，也支持把来自不同书籍的多条子笔记一起拖回顶层。每个拖动来源都携带完整可见选择，重复传输去重；放下后校验全部笔记，一次保存并注册一次撤销/重做。任一条已失效或存在未保存修改时整批停止，不会只移动部分笔记。多选时保留全部选择，详情面板显示笔记数量。拖到列表顶层插入位置或下方空白处转为独立笔记，最终位置遵循当前列排序。脱离书籍时沿用原书籍的普通文件夹归属，并保留在当前普通文件夹中。移动保留笔记 ID、正文、名称、标签与创建时间，自动保存并支持「撤销移动笔记」。回收站和有未保存冲突的笔记不可拖动；跨书库、过期拖动及无效目标均会拒绝。

工具栏「＋」菜单包含「添加书籍…」和「新建笔记」；选中一本书籍时在该书下创建子笔记，并展开父书籍、打开右侧编辑器；未选中书籍或选中笔记时创建独立笔记，沿用当前普通文件夹。多选书籍和回收站内禁用新建笔记。列表中右键单本书 →「新建笔记…」，右侧编辑器会自动关联右键操作的书籍；多选和回收站书籍不显示此项。每本书可以有多条子笔记；详情面板「笔记」标题旁显示数量和新建加号，区块内仅列出已有笔记的标题行，点击打开正文；不重复显示区块标题和空白说明。点击加号直接进入右侧正文编辑器，回收站书籍不显示加号。侧栏不设单独的笔记分组；独立笔记作为顶层条目，与书籍一起显示在全部书籍或所属文件夹的中间表格中，不再单列底部区域；仅笔记搜索结果同样保留表头与列设置。点击笔记在右侧直接编辑，点击侧栏「全部书籍」下方的「回收站」统一查看已删除书籍和笔记。回收站的侧栏右键菜单仅保留「清空回收站…」，为空时禁用，执行前显示确认提示。

列表采用书籍与笔记的层级表格：有子笔记的书籍左侧显示展开箭头，展开后笔记缩进显示在该书下方。笔记行保留自己的标题和图标，作者、出版社等书籍字段留空。选中笔记后即可在右侧直接修改正文；双击或右键「编辑笔记」会将光标移到右侧正文，不打开编辑弹窗。也可将笔记移入回收站。选中笔记不会将所属书籍加入批量操作。

新建笔记会立即建立可撤销的空白条目，自动展开所属书籍并将光标放到右侧正文；搜索笔记标题、正文或标签命中时也会展开所属书籍。点击列标题排序共同调整书籍与独立笔记的位置，标题使用笔记显示名称，添加/修改日期使用笔记自身时间，其他书籍专属字段留白；子笔记始终留在所属书籍下，按创建顺序显示。列宽自动适配同时计算独立笔记标题。折叠包含当前笔记的书籍时选择回到书籍。回收站中可展开查看随书籍保留的笔记，单独删除的子笔记及独立笔记直接显示为条目。恢复所选笔记时，如所属书籍也在回收站，需同时选择书籍或先恢复书籍。

默认笔记面板只显示格式工具栏和正文，编辑区铺满所在面板，去掉外围灰色留白、圆角卡片边框，以及底部名称、标签、所属书籍与文件夹设置和常驻保存状态。新笔记默认以正文第一条非空内容行命名，去掉 Markdown 标记并最多显示 80 个字符，正文为空时显示「新笔记」；首行改变时列表名称随之更新。原有自定义名称、标签、关联书籍和文件夹仍保存在数据与备份中，编辑正文不会清空这些信息，当前界面不再提供这些字段的编辑控件。新建子笔记关联所选书籍；在普通文件夹中新建独立笔记沿用当前文件夹。

修改自动保存到本机，无需保存按钮。只有保存失败时才出现错误、重试与另存入口。笔记列表、独立笔记条目以及书籍详情中的笔记行可通过右键移入回收站；回收站仍显示只读内容和恢复/永久删除操作。修改可撤销，没有实际变化时不产生额外历史；过期编辑器不能覆盖后来保存的版本。

顶部搜索匹配笔记标题、正文和标签，在书籍范围内也能通过子笔记找到所属书籍。高级书籍筛选中的旧「笔记」条件仍指书籍备注，新笔记请使用顶部搜索。笔记标签随笔记保存和检索，目前不参与侧栏的书籍标签交集筛选。

旧版单份笔记保留在「书籍备注（原有笔记）」中；点击「转为书籍笔记并编辑」可将完整内容移动到一条子笔记并在右侧编辑，支持撤销。升级不会自动清空、拆分或重复复制旧笔记。

笔记删除后进入统一回收站，恢复时保留关联与内容。书籍进入回收站，其子笔记随之进入回收站并保持只读；恢复书籍会恢复随书籍删除的子笔记，单独删除过的子笔记仍需选中恢复。永久删除书籍会一并删除其全部子笔记；单独永久删除笔记则保留所属书籍及其他笔记。合并书籍将子笔记移到主记录，撤销会恢复原关联。撤销新建书籍或文件夹时，若后来新增了子笔记、子文件夹或归属，会停止以保护这些内容。

回收站支持 ⌘ 点选多项、⇧ 连续选择和 ⌘A 全选，可混合选择书籍与笔记。右键和右侧详情均提供批量恢复及永久删除。批量恢复在一个事务内完成，可一次撤销或重做。若任一笔记的所属书籍仍在回收站且未选中，整批恢复不可执行，请先补选或恢复其书籍。

永久删除前显示实际删除数量，所选书籍下的全部子笔记也包含在计数中，父子条目同时选中不会重复计算。确认框明确提示无法撤销，并提供取消。侧栏「回收站」右键可清空回收站，范围包括全部已删除书籍、独立笔记、单独删除的子笔记及随书籍删除的子笔记，不受当前搜索筛选限制。正常在库的书籍和笔记不受影响。

确认时锁定条目快照，执行前再次核对；记录已被编辑、恢复或移除、书籍新增子笔记，或清空范围发生变化时，整批停止并要求重新确认。永久删除经统一事务提交，成功后清理书库撤销历史，避免旧操作复活已永久删除的内容。存在未保存草稿的所选笔记应先保存或另存，再永久删除。

切换条目或关闭窗口前，已经输入的修改已同步写入本地书库。发生冲突或写入失败时保留当前草稿，并尝试将恢复副本写入应用自己的 `Bookshelf/NoteDraftRecovery` 目录。底部「未保存草稿」可重新打开，选择「重试保存」或「另存为新笔记」；另存不会覆盖已有版本。恢复副本写入也失败时会明确提示，不显示为已保存。恢复草稿不属于完整 JSON 备份，需先成功保存为笔记。

主表格按当前范围和搜索条件显示笔记，右侧正在编辑的内容独立保留；筛选变化不会丢弃未保存草稿。回收站仍只读，恢复后再编辑。原生文本编辑撤销与书库操作撤销各自保留。

右侧编辑器采用原生 NSTextView / SwiftUI，正文始终以可编辑的格式显示，没有「编辑／预览」模式切换。

- 输入 `# ` 至 `###### ` 转为标题，输入 `**加粗**`、`*斜体*`、`~~删除线~~`、行内反引号或 `[文字](网址)` 后直接转换格式。
- 行首输入 `- `、`1. `、`- [ ] `、`- [x] ` 或 `> `，生成列表、任务或引用。列表按 Return 续写，空项再次 Return 退出；标题 Return 后回到正文。行首三个反引号加可选语言并按 Return 进入代码块，空代码行 Return 退出。
- 工具栏直接修改选中文字或所在段落；加粗和斜体支持 ⌘B / ⌘I。「段落格式 → 正文」可清除段落类型；链接在小面板中填写实际网址。粘贴 Markdown 会直接显示对应格式。
- 自动转换是独立的撤销步骤：⌘Z 先恢复刚输入的 Markdown 标记，再撤销之前输入。编辑器的撤销栈按笔记隔离；中文输入法组合阶段不执行自动转换。

存储仍为 Markdown，无数据库字段迁移。打开、选中或查看旧笔记不会重新保存；实际编辑后将格式化内容序列化为等价 Markdown，符号转义、列表标记和围栏可能规范化。正文搜索、自动命名、草稿恢复和 JSON 备份继续使用同一正文。回收站内容只读显示。

当前支持上述基础格式，暂无表格专用编辑、数学公式、嵌套引用工具或 Zotero HTML 笔记导入。未支持的语法保留为文字；图片保留替代文字和原始网址，不加载附件或远程资源。HTML 不执行，只有 http、https、mailto 链接可点击。无需新增网络或文件权限。

## 备份和导入

完整 JSON 备份升级为 `schemaVersion: 4`，包含空文件夹、父子层级、独立笔记、书籍子笔记及其回收站状态；继续读取版本 1/2/3。旧应用不能读取版本 4。此轮不增加数据库字段或修改 JSON 键；`title` 留空代表自动命名，`body` 保留完整 Markdown 源码。含空名称的新备份应使用此版本或更新版本恢复，先前要求笔记标题非空的版本不支持。

导入预览单独列出文件夹与笔记，可以取消该部分。普通文件夹同 ID 或同名沿用本地名称和位置；同 ID 笔记保留本地内容。新笔记的书籍和文件夹关联会映射到导入后的实际 ID；选择将书籍另存为新记录时，子笔记跟随新记录。跳过的书籍若没有对应本地 ID，其子笔记跳过并计入结果。取消层级/笔记导入时，书籍仍按旧名称恢复普通文件夹归属。

导入前检查父子循环、缺失关联、重复 ID 和无效记录；书籍、文件夹、智能规则、笔记共用一个事务。写入失败整体回滚，导入可以整次撤销/重做；预览后相关本地记录发生变化时停止。

## 实现与验证

- `BookCollection.parentID` 为可空字段，旧文件夹自然成为顶层；新增 `LibraryNote` 实体，既有字段和默认存储路径保持兼容。
- `ManualCollectionRecord` / `NoteRecord` 为值快照；`CollectionCommands` / `NoteCommands` 处理意图，`OrganizationStore` 在 Repository 的事务中写入。
- 查询、提交后通知和撤销历史支持笔记 ID 与文件夹图；`TrashCommands` 为批量恢复、永久删除和统一清空生成快照，核对范围后统一提交事务，永久删除后清理相关撤销历史。
- `NoteEditingSession` 保留每个窗口的编辑状态，自动保存经 `NoteCommands` 提交；失败草稿由 `NoteDraftRecoveryStore` 保留，成功保存后清理恢复副本。

新建普通文件夹直接在左侧边栏显示临时名称输入行，不再弹出新建窗口。顶部加号与侧栏右键「新建文件夹」在顶层插入；右键「新建子文件夹」在对应父级下插入并自动展开路径、滚动到输入行。默认名称为可用的「新建文件夹」（重名时递增编号），自动全选以便直接输入。回车保存并选中新文件夹；离开输入框保存有效名称，空白则取消；Esc 取消且不写入书库。重名或保存失败在原行显示提示并保留输入。保存继续支持一次撤销与重做，既有层级、排序及书籍／笔记归属逻辑不变。智能文件夹继续在高级筛选面板填写名称与规则。

普通文件夹和智能文件夹的右键「重命名」直接在左侧原行编辑名称，自动全选原名；回车保存并选中该文件夹，Esc 恢复原名且不写入，离开输入框保存有效名称。空名称回车和同类型重名均在原行提示；空白失焦取消。编辑期间保持原有顺序、父子层级和展开状态；取消或未修改名称不会更新修改时间或增加撤销记录。保存复用原有事务与撤销机制，保留书籍、笔记归属和智能规则，拒绝覆盖其他操作已更改的记录。普通文件夹的「移动文件夹…」单独保留上级选择，不再混合名称编辑。
