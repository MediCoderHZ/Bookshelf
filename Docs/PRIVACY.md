# Bookshelf 隐私政策（发布草案）

最后更新于 2026 年 11 月 28 日

应用名称：Bookshelf。维护者：MediCoderHZ。项目地址：[MediCoderHZ/Bookshelf](https://github.com/MediCoderHZ/Bookshelf)。

## 本地存储

书籍元信息、个人备注、标签、笔记默认保存在用户 Mac 的应用沙盒中，也可通过设置迁移到用户选择的自定义目录。迁移前备份，原数据库保留；自动备份和恢复草稿仍在本机应用目录。目录路径与持久访问授权保存在本机，不上传；完整性检查只读处理本机数据库。开发者不运营接收书库数据的服务器，应用不会自动上传完整书库。应用不内置广告或行为分析 SDK。

高级筛选和智能文件夹只在本机计算，筛选值不发送至在线检索来源。智能文件夹名称与条件保存在本机，包含在未单独加密的 JSON 备份中，可通过侧栏移除。移除智能文件夹不删除书籍；已经导出的备份需另行保管或删除。

自动备份默认在应用运行时每小时保存一次，包含书籍、笔记、回收站、文件夹、智能规则及可用的恢复草稿，保存在应用沙盒的 `Library/Application Support/Bookshelf/Backups/`。默认保留最近 30 份定时与手动备份；升级前快照单独保留最近 10 份，仅在新备份成功后清理超出数量的有效旧备份。备份不上传、未单独加密；可在设置中调整频率和保留数量、关闭定期备份或导出备份到所选位置。升级前备份始终启用。删除书库条目不会立即清除已有备份中的记录。损坏或无法识别的备份不会自动删除。

## AI 元信息补全

在编辑书籍页面请求 AI 补全时，Bookshelf 将当前表单中的标题、作者、ISBN 和出版信息等书目字段发送给你配置的模型服务。服务方可能按其政策处理请求。模型密钥按服务地址存储在本机钥匙串中。

MCP 默认关闭。开启后，当前 Mac 上能访问该用户专用套接字的客户端可以查询书目、读取书目字段并提交建议。客户端可能将返回的信息发送给自己的模型。两种模式都排除笔记、标签、文件夹、回收站、附件内容和文件路径。只有在 Bookshelf 内确认的字段才会写入书库。

## 在线检索

仅在点击搜索后，应用将输入的书名或 ISBN 发送至所选来源：豆瓣 www.douban.com、Goodreads www.goodreads.com 或 Open Library openlibrary.org。选择“全部已启用来源”会分别请求上述启用来源；停用的解析器不参与。选择候选后读取对应详情页，豆瓣详情来自 book.douban.com。ISBN 搜索可能直接返回详情。服务方会收到查询、页面请求内容、IP 地址、应用版本等常规网络信息，可能按其政策保留服务日志。不会随请求发送个人备注或完整书库。

检索用于展示和填充书籍信息。应用不要求登录 Open Library，不主动发送用户账户标识；这不代表服务方不会记录 IP 地址等请求信息。第三方日志的保留、删除与用途受 [Internet Archive 服务与隐私说明](https://archive.org/about/terms.php)约束，应用开发者无法代其删除日志。

用户可以取消搜索、继续手动录入。取消会停止当前检索任务，已经发出的请求无法撤回。

## 软件更新

启用 Sparkle 的版本会在你选择「Bookshelf → 检查更新…」或同意自动检查后，从 `raw.githubusercontent.com` 读取公开的更新清单。下载时会访问 GitHub Releases 上的更新包。GitHub 可能收到 IP 地址、应用版本等常规网络信息。请求不包含书籍、笔记、标签或书库备份。Sparkle 的可选系统分析默认关闭。[更新清单](https://raw.githubusercontent.com/MediCoderHZ/Bookshelf/main/Distribution/Updates/appcast.xml) · [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

GitHub Releases 已发布的 0.1.0 安装包关闭了应用内更新，不会自动发起上述请求。其用户可在浏览器中访问 GitHub Releases，手动下载安装新版。

## 网页解析器与自定义规则

仅在点击提取或选择列表中的图书后，应用向已启用解析器匹配的网址请求页面。网站会收到请求网址、IP 地址、应用版本等网络信息，可能依其政策保留服务日志；开发者无法代其删除日志。

内置豆瓣解析器使用 book.douban.com，详见[豆瓣个人信息保护政策](https://www.douban.com/about/privacy)。自定义 JSON 规则的目标网页在导入确认时显示，其数据处理以对应网站的政策为准。规则仅保存在本机，导入、启用和移除不请求网站；用户点击在线提取后才发出页面请求。

内置 Goodreads 解析器请求 www.goodreads.com 的公开页面。数据处理参见 [Goodreads 隐私政策](https://www.goodreads.com/about/privacy)。应用不登录 Goodreads，不使用网页中附带的认证信息请求 API，不保存页面中的用户资料、广告或认证字段。只提取并预览书籍元信息；来源和提取时间随书籍保存。用户可以在元信息解析器窗口中停用 Goodreads。

应用使用临时网络会话，不读取浏览器 Cookie、不登录网站、不执行网页中的脚本、不上传书库和笔记。来源网址与提取时间随书籍保存在本机并包含在书库备份中。三个来源的解析脚本从当前数据库同级的 `translators/` 目录加载。自定义规则与启用状态单独保存在本机，书库备份不包含规则，可单独导出。可停用任何解析器、移除自定义规则。取消请求无法撤回已发出的信息。点击浏览器链接后，适用浏览器和网站自身设置。

## 文件访问与备份

Bookshelf 将附件副本保存在书库或用户指定的文件夹中。使用自定义文件夹时，书库在本机保存文件夹访问授权和指向副本的软链接。通过「链接文件」添加的附件在本机保存访问原文件的授权。书库的 JSON 备份包含已添加副本的文件内容，链接文件仅包含文件名，网页链接包含标题和完整网址。保存网页链接时不会请求网页内容。打开文件时由系统默认应用处理，打开网页链接时由默认浏览器访问该网址。

用户主动打开 HTML、安装插件、导出规则、保存或恢复备份、选择自定义数据目录时，应用访问明确选择的文件或位置。自定义目录通过安全作用域书签保留跨重启的读写授权。应用会加载当前数据目录中的已安装规则，不会扫描用户的其他文件夹。HTML 在本机解析，不执行脚本、不加载其引用资源。数据库与 JSON 备份包含书籍、来源记录、个人备注、标签、文件夹归属，未单独加密，请妥善保管；选择云盘等位置可能由该服务同步，不建议在其中存放正在使用的数据库。

## 数据共享

应用不出售用户数据。除用户主动发起在线检索、网页提取所需的信息外，不向开发者或第三方传输书库数据。用户主动联系支持时，应避免发送不必要的私人笔记、完整备份或账号资料。

## 保留与删除

移入回收站后，书籍元信息、笔记、分类仍保存在本机，可恢复。合并后的其他原记录也保留在回收站。只有永久删除或清空回收站才删除这些记录；永久删除无法撤销。本次窗口会话内的撤销记录暂存于内存，退出后不保留。JSON 备份包含回收站状态和字段来源。移除应用后 macOS 可能保留应用容器；清除前请先备份。已导出的备份不会被自动删除。第三方服务日志的保留与删除由服务方负责。
